# adopcion-mascotas
# 🐾 Sistema de Gestión de Mascotas

¡Bienvenido al proyecto de Gestión de Mascotas! Esta es una aplicación móvil y web desarrollada con **Ionic** y **Angular** que permite administrar un catálogo de mascotas (agregar, editar y visualizar sus estados como "Disponible", raza, edad, etc.). La aplicación maneja la carga temporal de imágenes mediante conversión a Base64 en memoria local.

---

## 🚀 Requisitos Previos

Antes de comenzar, asegúrate de tener instalado lo siguiente en tu equipo:

*   **Node.js**: Versión LTS (recomendado v18 o superior). Puedes descargarlo de [nodejs.org](https://nodejs.org/).
*   **Angular CLI**: Instálalo globalmente ejecutando:
```
    npm install -g @angular/cli
    ```
*   **Ionic CLI**: Instálalo globalmente ejecutando:
```
    npm install -g @ionic/cli
    ```
